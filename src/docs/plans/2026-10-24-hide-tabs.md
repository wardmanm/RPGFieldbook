# Hide Tabs per Character: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A player hides the tabs a character doesn't use (Settings → Sheet display → Tabs), saved
per character, and easy to undo (#52).

**Architecture:** One field, `character.hiddenTabs`, plus a few helpers in `40-sheet.js`, beside
`selectTab()`:
- `HIDEABLE_TABS`, `TAB_LABELS`
- `isTabHidden`, `cleanHiddenTabs`, `setTabHidden`, `applyHiddenTabs`

`renderAll()` calls `applyHiddenTabs()`, so loading, switching and new characters all apply the
right tabs. Three things look at it: `selectTab()` (a guard), `jumpToNote()` (it unhides, with a
toast), and `leaveCombatTab()` (back to the Sheet). The Settings page writes it through
`setTabHidden()`.

**Tech Stack:** Plain ES2020 concatenated into one `<script>`, no modules; Node suites through
`src/tests/harness.js`; the project's Playwright MCP for QA.

**Spec:** `src/docs/specs/2026-10-24-hide-tabs-design.md`. Read it first.

## Review Focus

1. **Corrupt or hand-edited `hiddenTabs`.** A string, an object, `["sheet","combat","bogus","spells","spells"]` or `null` cleans to only real hideable names, each once. The Sheet tab never hides. → Task 1, "migrate cleans hiddenTabs".
2. **Switching to a character whose list hides the tab you're on.** The Sheet shows; no empty panel is left behind. → Task 1, "applyHiddenTabs moves off a hidden active tab".
3. **The icon-tab or narrow layout overriding `hidden`.** `.tab` sets its own `display`, which beats the browser's `[hidden]` rule, so a `.tab[hidden]{display:none!important}` rule is needed. → Task 1, the CSS check.
4. **A note into a hidden tab.** The tab comes back, the toast names it as the bar does (Bio, not story), and the character saves. → Task 2, the jump test.
5. **The swords' way back to a tab that was hidden meanwhile.** It lands on the Sheet, and focus never goes to a hidden button. → Task 2, the `leaveCombatTab` test.

```js
/* ---- hidden tabs (#52) ----
   Per character: the word tabs a player has switched off in Settings → Sheet
   display. The Sheet and the combat swords can never be hidden. */
const HIDEABLE_TABS=["spells","inventory","story","journal","rules"];
const TAB_LABELS={spells:"Spells",inventory:"Inventory",story:"Bio",journal:"Journal",rules:"Rules"};
function isTabHidden(name,c){
  c=c||character;
  return HIDEABLE_TABS.indexOf(name)>=0&&!!c&&Array.isArray(c.hiddenTabs)&&c.hiddenTabs.indexOf(name)>=0;
}
/* migrate()'s cleaner: only real hideable names, each once, in order */
function cleanHiddenTabs(v){
  const out=[];
  (Array.isArray(v)?v:[]).forEach(t=>{if(HIDEABLE_TABS.indexOf(t)>=0&&out.indexOf(t)<0)out.push(t);});
  return out;
}
function applyHiddenTabs(){
  document.querySelectorAll(".tab[data-tab]").forEach(b=>{b.hidden=isTabHidden(b.dataset.tab);});
  const act=(document.querySelector(".tabpanel.active")||{id:""}).id.replace(/^tab-/,"");
  if(isTabHidden(act))selectTab("sheet");
}
function setTabHidden(name,hide){
  if(HIDEABLE_TABS.indexOf(name)<0)return;
  const list=cleanHiddenTabs(character.hiddenTabs).filter(t=>t!==name);
  if(hide)list.push(name);
  character.hiddenTabs=list;
  applyHiddenTabs();scheduleSave();
}
```
