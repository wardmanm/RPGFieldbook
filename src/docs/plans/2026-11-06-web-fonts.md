# Web Fonts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The page makes no font request at all: the three families it uses today (Grenze Gotisch,
Cinzel, EB Garamond) are embedded in its stylesheet, Latin only, so a sheet looks the same offline
as it does online today (#144).

**Architecture:** A dev-only script, `scripts/fetch-fonts.js`, run by hand like `fetch-icons.js`,
asks the Google Fonts css2 API for exactly the template's current request, keeps the `/* latin */`
faces, downloads their woff2 files and each family's `OFL.txt`, and writes a committed, generated
CSS fragment, `src/css/90-fonts.css`: a comment carrying the copyright notices and the full SIL
Open Font License 1.1, then one `@font-face` per file with a `data:font/woff2;base64,` URL. The
template's three Google lines go. A new guard in `rules-data.js` asserts the built page and its
sources load nothing from a third-party address.

**Tech Stack:** Node (built-in `fetch`, no dependencies), plain CSS, the Node test harness
(`src/tests/harness.js`).

**Spec:** the design Mike approved in chat on 2026-11-06, restated in full under Global
Constraints (there is no spec file).

**Branch:** `issue/144-web-fonts` in `.claude/worktrees/144`. Commit `src/`, `scripts/fetch-fonts.js`,
`README.md`, `CLAUDE.md` (its fragment count only) and this plan; never `dist/fieldbook.html` or
`docs/CHANGELOG.md`. Verify with `./build.sh --no-zip && ./src/tests/run.sh`.

## Global Constraints

- **Same families and weights as the template's link today:** Grenze Gotisch 500/700/900, Cinzel
  500/600/700, EB Garamond 400/500/600 plus italic 400. The css2 query the script sends is exactly
  `family=Grenze+Gotisch:wght@500;700;900&family=Cinzel:wght@500;600;700&family=EB+Garamond:ital,wght@0,400;0,500;0,600;1,400&display=swap`.
- **Latin only:** Google's `latin` subset with its exact `unicode-range`. Latin Extended is not
  included; "Ł" falls back to Georgia for that letter.
- **One `@font-face` per file.** Each style is one woff2 covering every weight requested: four
  files (Cinzel normal, EB Garamond normal, EB Garamond italic, Grenze Gotisch normal), variable
  except the single-weight italic. Each block's
  `font-weight` is the range of the weights requested for it (`500 900`, `500 700`, `400 600`,
  `400`), so a weight the CSS asks for outside it (the app sets 800 and 900 on `--head` and
  `--body`) clamps to the same face it does online today. (Corrected after the final review: a
  weight *inside* a range between two requested ones, such as Grenze Gotisch's 800, renders as
  asked where Google snapped it to 900; `.hcard-name` now asks for 900, and `docs.js` checks
  every weight.)
- **Family names match `00-tokens.css` exactly:** `"Grenze Gotisch"`, `"Cinzel"`, `"EB Garamond"`.
- **`font-display:swap`** on every block.
- **Measured 2026-11-06:** Cinzel 25,888 B, EB Garamond normal 44,172 B, EB Garamond italic
  25,412 B, Grenze Gotisch 42,272 B; 137,744 B in all, about 184 KB as base64. The built file is
  1,396,238 B before.
- **No Reserved Font Name.** Subsetting modifies the font under the OFL; a family whose `OFL.txt`
  declares an RFN stops the script (and this work) before anything is written. Checked 2026-11-06:
  none of the three declares one.
- **The licence travels in the file:** each family's copyright notice and the OFL 1.1 text, once,
  in the fragment's comment, present in the built `dist/fieldbook.html`.
- **The fetch is never part of `build.sh` or CI.** Hosts the script may reach:
  `fonts.googleapis.com`, `fonts.gstatic.com`, `raw.githubusercontent.com`.
- **Byte hygiene:** the fragment has no CR, no BOM, no trailing whitespace, and ends in exactly one
  `\n`.
- **Credits:** Settings → Credits and README §10 name the three families and "SIL Open Font
  License 1.1", linked to `https://openfontlicense.org`.
- **The guard:** no `<link href>`, `<script src>`, other fetching attribute, CSS `@import` or CSS
  `url(...)` pointing at `http:`, `https:` or `//`. Plain `<a href>` links and the `fetch()`
  update checks are allowed.

## Review Focus

- **Google changes its answer** (static files per weight, a renamed subset, woff instead of woff2,
  a different set of faces): the script must die naming what it got and write nothing. Pinned by
  the script's strict parse, exercised once by a `--dry-run` in Task 1.
- **Someone renames a token's family without re-running the script:** the page would silently fall
  back to Georgia. Pinned by the tokens-vs-fragment parity check in `docs.js` (Task 1).
- **Someone re-adds a CDN link, a remote `@import` or a remote `url()`:** pinned by the guard in
  Task 2, which runs on the built page and on the sources, plus its own positive and negative cases
  so it is seen to fail.
- **A truncated or mangled base64 blob:** the page would fall back with no error. Pinned in `docs.js`
  by decoding each blob and checking `wOF2` and the byte count its comment states (Task 1).
- **The licence comment dropped by some future build step** (a minifier): pinned by the built page
  containing the fragment byte for byte (Task 2).

**Interfaces:**
- Produces: `src/css/90-fonts.css`, whose shape the tests read:
  - a header comment containing `GENERATED, DO NOT EDIT` and `node scripts/fetch-fonts.js`;
  - one notice line per family, `   <Family>: Copyright …`;
  - the OFL text from its `SIL OPEN FONT LICENSE Version 1.1 - 26 February 2007` line to the end;
  - per face, a one-line comment `/* <Family>, <style>, weights <w>: latin, <n> bytes, from <url> */`
    immediately followed by `@font-face{font-family:"<Family>";font-style:<style>;font-weight:<a>[ <b>];font-display:swap;`,
    then `  unicode-range:<Google's latin range>;`, then
    `  src:url("data:font/woff2;base64,<b64>") format("woff2")}`.
- Script functions (cited by the wiki): `css2Url()`, `parseLatinFaces(css)`, `licenceParts(text)`,
  `fragmentCSS(faces, notices, body)`.

    `css2Url()` builds the query in Global Constraints from it (the italic axis form only when a
    family has italic faces).

  - `parseLatinFaces(css)` → `[{family, style, weights, url, range}]`, one per (family, style):

    and unless every requested face was found.
  - Download each file: `res.ok`, first four bytes `wOF2`; die if the total exceeds 256 KiB (the
    Latin set is ~135 KiB; more means Google changed what it serves, and the size is a decision).

    The three bodies must be identical (the comment carries the text once), else die.
  - `fragmentCSS(faces, notices, body)` → the fragment in Interfaces, faces in `FAMILIES` order.
    Before writing, die on any CR, BOM or trailing whitespace in the output.
  - Print each file's bytes, the total, the base64 total and the fragment size; `--dry-run` prints
    the same plus each notice and "no Reserved Font Name", and writes nothing.

- [ ] **Step 1: Write the failing guard.** A local `thirdPartyLoads(text)` returning offending
  snippets (each cut to 120 characters):
  - tags `/<([a-zA-Z][\w:-]*)\b([^<>]*)>/g`; an attribute is a load when it is `src`, `srcset`,
    `imagesrcset` or `poster` on any element, `data` on `<object>`, or `href`/`xlink:href` on any
    element but `<a>` and `<area>`; it offends when its value, or any `srcset` candidate, starts
    `http:`, `https:` or `//`;
  - `/@import\s+(?:url\(\s*)?["']?\s*(?:https?:)?\/\//gi`;
  - `/(?<![\w$.])(?<!new\s)url\(\s*["']?\s*(?:https?:)?\/\//gi` (CSS is case-blind; JS's
    `new URL(` and `extUrl(` are not CSS).
  Checks:
  - `constraint 1: the guard sees each way a page loads a remote resource` — each of these yields
    a hit: `<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=X">`,
    `<link rel="preconnect" href="//fonts.gstatic.com" crossorigin>`,
    `<script src="https://cdn.example.com/x.js"></script>`, `<img src='http://example.com/a.png'>`,
    `<img srcset="a.png 1x, https://example.com/b.png 2x">`, `<use href="https://example.com/s.svg#i"/>`,
    `@import url("https://example.com/a.css");`, `@import 'https://example.com/a.css';`,
    `.x{background:url(https://example.com/a.png)}`, `src:URL( "//example.com/f.woff2" )`;
  - `...and passes what is not one` — none yields a hit:
    `<a href="https://game-icons.net" target="_blank" rel="noopener">`,
    `fetch("https://api.github.com/repos/x/y/releases/latest")`, `.card::before{filter:url(#rough)}`,
    `src:url("data:font/woff2;base64,d09GMgAB")`, `new URL("https://example.com/x")`,
    `<html data-tabs="labels">`, `<img src="${esc(safeImgSrc(u))}">`;
  - `constraint 1: the built page loads nothing from a third-party address` on `dist/fieldbook.html`;
  - `...nor do its sources` on the template, `manifest.html`, `manifest.css` and `manifest.js`;
  - `the built page carries 90-fonts.css byte for byte, its licence comment included`.
