# Vitals pencil and the HP dialog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Vitals gets the list cards' pencil (it hides the portrait buttons and locks Max HP, and the
padlock goes), a touchscreen tap on the HP bar opens a Hit points dialog (amount, then Damage, Heal or
Temp, with Set exactly in a fold), and the bar's numbers and the − and + glyphs sit centred.

**Architecture:** The lock becomes `character.editHide.vitals`, read by one helper and set from code by
another, both in `87-notes.js` beside the other edit-toggle code. The dialog's logic is pure functions
in `66-coins-hp.js` (preview, amount check, Set exactly's parse, the two model writes) that the
harness can call; `90-boot.js` only wires the tap. Centring is CSS: the bar becomes a three-column
grid whose outer tracks are equal, the numbers are sized to their content from `renderHP()`, and a
container query on `.rail-hp` moves Temp out of the bar where it would collide.

**Tech Stack:** plain JS fragments concatenated into one file, CSS fragments, Node suites in `src/tests/`.

**Spec:** `src/docs/specs/2026-11-06-vitals-hp-design.md` (approved by Mike, 2026-11-06).

## Global Constraints

  centring.

- Produces, all in `66-coins-hp.js`:
  - `hpTouch() -> boolean` — `(pointer:coarse)` matches.
  - `hpAmount(raw) -> number|null` — strips `[\s,]`, then `/^\d+$/` and ≥ 1, else `null`.
  - `hpQuick(hp, effMax, n) -> {damage:{cur,temp}, heal:{cur}, temp:{temp}}` — what each tap would
    leave, as the model stores it (a spent-out temp is `""`; a blank Current with no overflow stays `""`).
  - `hpQuickText(hp, effMax, n) -> {damage, heal, temp}` — "→ 22, no temp" / "→ 19" (had no temp) /
    "temp 3 → 1" or "temp 3 → 0" (temp soaks it all); "→ 33"; "3 → 7" or "→ 7".
  - `hpNowText(hp, effMax) -> string` — "26 / 38 · temp 3"; "0 / —" with nothing set; no "· temp" without temp.
  - `hpBarLabel(hp, effMax) -> string` — "Hit points 26 of 38, temp 3 — change" (no "of" with no maximum).
  - `hpQuickApply(kind, n) -> boolean` — `"damage"` → `adjustHP(-n)`, `"heal"` → `adjustHP(n)`,
    `"temp"` → `hp.temp=n` then `clampHP()`; `false` for any other kind or a non-amount `n`.
  - `hpSetParse(vals, withMax) -> {hp:{cur,temp[,max]}, bad:[label]}` — each box: `[\s,]` stripped,
    blank → `""`, whole number ≥ 0 → that number (Temp 0 → `""`), else its label in `bad`;
    `max` only when `withMax`.
  - `hpSetApply(hp) -> boolean` (Max changed) — writes cur and temp, and max only if present and
    Vitals is unlocked; then `clampHP()`.
  - `hpDialogHTML(hp, effMax, withMax) -> string`; `openHPDialog() -> void` — ids `hpqAmt`, `hpqDmg`,
    `hpqHeal`, `hpqTemp` (each with a `.hpq-res` line), `hpqSet` (`<details>`), `hpqCur`, `hpqMax`,
    `hpqTmp`, `hpqMsg`, `hpqCancel`, `hpqApply`. No `data-hp` or `data-path` on any of them.
